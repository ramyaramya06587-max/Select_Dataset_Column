# Task 18: Select Dataset Columns Using Pandas

## Objective
To learn how to select specific rows and columns from a dataset using Pandas `loc` and `iloc`.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Iris Dataset (CSV)

## Description
This task demonstrates how to select specific columns, rows, and combinations of rows and columns from the Iris dataset using Pandas. The `loc` method is used for label-based selection, while `iloc` is used for integer-position-based selection.

## Operations Performed
1. Loaded the Iris dataset using Pandas.
2. Displayed the first five records.
3. Selected specific columns using `loc`.
4. Selected specific columns using `iloc`.
5. Selected rows using `loc` and `iloc`.
6. Selected specific rows and columns together.

## Learning Outcome
Learned how to use Pandas `loc` and `iloc` to extract required data efficiently from a DataFrame.

## Conclusion
Successfully practised row and column selection using Pandas on the Iris dataset.
